# Provenance & Sources — Read-Only Native-Parity Audit

**Scope:** exactly `nmem_provenance` and `nmem_source` from the **Provenance & Sources** domain. This audit examined the selected upstream checkout at **`2015cb9b0973a6fe14a3bc547c932d64d6ced203`** and the current iOS sources named below. It made **no source-code edits** and did not treat any other NeuralMemory domain as in scope.

## Decision standard

A tool is **ready** only when the iOS app has all three: (1) the exact observable upstream behavior, (2) actual `NativeAgentEngine` schema/dispatch reachability, and (3) tests covering that behavior and a tool-using agent cycle that reaches a terminal run phase. Existing adjacent data fields, UI display, generic remote MCP support, or placeholder documentation do **not** satisfy that standard.

> **Result: neither exact tool is ready.** Both are **partial** only because WaifuClaw persists limited, per-fact local source/provenance metadata. Neither has the exact tool contract, source/audit graph persistence, native routing, or lifecycle tests.

## Transport and implementation boundary

- The selected upstream is **MIT** (`/home/ubuntu/neural-memory-source-audit/LICENSE:1-13`). Its documentation says its tools are MCP tool calls and lists **63 tools via MCP stdio** (`docs/api/mcp-tools.md:3-7`); its Python entry point runs the server over stdin/stdout and depends on `aiosqlite` storage (`src/neural_memory/mcp/server.py:802-945`). This is **not** an iPhone-native implementation.
- WaifuClaw's local memory component is a new Foundation + SQLite3 graph with no remote client, endpoint, credential storage, or model invocation (`WaifuClaw/Local/Memory/UPSTREAM.md:16, 28-34`; `LocalNeuralMemoryModels.swift:260-271`). It stores user-approved facts and local metadata, not upstream-compatible provenance/source objects.
- The iOS `NativeMCPConnector` is a **remote Settings/UI** facade: models must never receive it and each remote call needs UI-issued one-use approval (`WaifuClaw/Local/MCP/NativeMCPConnector.swift:4-5, 31-33, 117-141`). `NativeAgentEngine` neither references it nor offers its tools. It is therefore **not counted as phone-native memory parity**, even if a user manually connects an upstream MCP server.

## Current agent-cycle reachability

The production controller does pass a per-project memory-consent Boolean into the engine (`WaifuClaw/Local/Agent/NativeAgentController.swift:158-170`). The engine then performs only a **pre-model recall** when `memoryEnabled`, a workspace, and file tools are available; at most three local facts are formatted into model context and `memory.recalled` evidence is recorded (`NativeAgentEngine.swift:135-165`). It does **not** expose a memory/provenance/source callable tool. Its exact offered tool list is `list_files`, `read_file`, and, conditionally, `propose_edit` (`176-178, 326-343`); unknown names reach `Tool error: unavailable tool` (`298-323`).

Accordingly, no model-directed call can reach either requested native behavior today. The existing `NativeAgentEngineTests` cover normal completion, denied file access, and an edit proposal (`WaifuClawTests/NativeAgentEngineTests.swift:6-109`), not `memoryEnabled`, `memory.recalled`, `nmem_provenance`, or `nmem_source`. The XcodeGen spec includes all of `WaifuClaw/Local` in the app and all of `WaifuClawTests` in the unit-test target (`project.yml:32-100`), so the proposed tests would be real target members once implemented.

## Risks blocking a “ready” claim

1. **False parity risk:** source labels and capture provenance are useful local metadata, but calling them `nmem_source` or `nmem_provenance` would omit the upstream registry, graph links, audit stamps, output contracts, and route.
2. **Authority risk:** upstream’s optional actor is caller-supplied. On iOS, model text must not become an approval/verification authority; capture consent and model-sharing consent need a separate audit/source mutation authorization policy.
3. **Deletion integrity risk:** omitting source-link counting would allow deletion of a source still referenced by facts, violating the upstream linked-source supersede safeguard.
4. **Privacy/transport risk:** a manually configured remote MCP server is an external network integration with separate approval semantics. It cannot replace project-isolated, on-device registry/audit storage or prove agent routing.
5. **Test-gap risk:** no native tests establish the two exact schemas, persistence semantics, permission denial, or agent tool-loop exit. Therefore no readiness conclusion is justified.

## Audit limitations

This is a static, read-only source audit. Existing XCTest files were inspected but not executed in this Linux sandbox; the report does not claim test execution or passing iOS builds. The iOS working tree already contained unrelated modified/untracked files before this report was written; none were changed by this audit.
