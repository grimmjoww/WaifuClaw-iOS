# NeuralMemory source-to-iOS audit — Training and Import

**Scope:** exactly `nmem_train`, `nmem_train_db`, `nmem_index`, and `nmem_import`. This is a **read-only** source audit; no application or upstream source was changed.

## Audit basis and decision rule

- **Upstream selected fork:** `/home/ubuntu/neural-memory-source-audit` at the task-selected SHA `2015cb9`. The checkout’s `LICENSE` is MIT, but its implementation is a Python MCP server: `src/neural_memory/mcp/server.py:826-945` runs `nmem-mcp` over **stdio by default** (or an optional HTTP server), with Python storage/optional-package dependencies. That is not an iPhone-native implementation.
- **iOS tree inspected:** `/home/ubuntu/waifuclaw-ios-build` (working-tree `cf1e0abae3b438423f9a3feb2c0cb0d567ce027f`, with unrelated existing modifications/untracked files). Primary native evidence is under `WaifuClaw/Local/Memory`, `WaifuClaw/Local/Agent/NativeAgentEngine.swift`, and the corresponding XCTest files.
- **Ready definition:** an exact implementation of the named tool’s behavior and input contract, native agent-cycle tool offer/routing, and direct plus agent-lifecycle XCTest coverage. A data model, generic local-memory feature, exported JSON, remote MCP connection, or placeholder/proposed capability is **not** ready parity.
- **Result:** **no scoped tool is ready**. `nmem_train` and `nmem_index` have only prerequisite-like local building blocks, so are labeled **partial**; `nmem_train_db` and `nmem_import` are **missing**.

> The app has a deliberately limited, on-device approved-fact graph. It is a useful privacy-preserving feature, but it is not the upstream Python neural-memory brain, MCP stdio process, document/schema/code training pipeline, or external-system migration engine.

## Agent-cycle reachability finding

Current native memory use is **context injection only**, not tool invocation. If memory is enabled and a workspace is selected, `NativeAgentEngine` constructs `LocalNeuralMemoryStore`, recalls up to three approved facts, and inserts them into the system prompt (`NativeAgentEngine.swift:135-165`). It does not construct, advertise, or dispatch any of the four named tools.

The tool loop calls the provider with the narrow `tools` list, records `tool.selected`, then either handles `propose_edit` or calls `performTool`; unknown names return `Tool error: unavailable tool ...` (`NativeAgentEngine.swift:183-276`, `298-324`). Completion is reachable only after a provider turn with no calls and non-empty visible answer; then it stores the message, records `run.completed`, sets phase `.finished`, yields `.completed`, and finishes the stream (`203-217`). The existing generic lifecycle test proves this base exit for a plain response (`NativeAgentEngineTests.swift:6-28`), but it cannot prove any scoped tool route.

## Risks and implementation gates

1. **Parity risk:** the upstream tool names describe graph-training/migration systems, not simple fact insertion. Claiming parity from `LocalNeuralMemoryStore.capture` or JSON export would be materially false.
2. **Permission/privacy risk:** the native store intentionally requires per-write user approval and keeps data on device; unattended agent scans/training/imports would weaken that design unless capability, preview, scope, and consent gates are added.
3. **Mobile/runtime risk:** MIT Python MCP stdio plus Python extras (`aiosqlite`, extractors, third-party adapters) cannot be treated as an embeddable iOS implementation. Any remote MCP server is a distinct remote dependency and requires user-visible connection/credential policy.
4. **Contract risk:** `nmem_index` documentation/schema advertises a broad extension default, while the real handler defaults to `.py`; a native implementation must explicitly choose which behavior it is matching and test it.
5. **Lifecycle risk:** do not mark a tool ready until its direct XCTest and a model-tool-cycle test prove both successful terminal exit and denied-capability behavior; current tests only cover local facts and generic/file/proposal agent paths.

## Bottom line

- **Ready:** none.
- **Partial:** `nmem_train`, `nmem_index` (only underlying local approved-fact/workspace primitives, not tool parity).
- **Missing:** `nmem_train_db`, `nmem_import`.
- **Do not count:** the MIT Python MCP stdio process, a remote/manual MCP connector, a `.localDocument` enum case, local JSON export, or future-test descriptions as a native completed implementation.
