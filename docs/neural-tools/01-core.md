**Audit mode:** source-only, read-only. No source code, tests, project files, or configuration were edited. This report does **not** claim that any XCTest was executed; it reports the test coverage present in source and gives falsifiable tests needed for parity.

## Decision rule and top-line result

**Ready** requires all three: (1) exact upstream behavior/contract, (2) a native tool route reachable in a real agent cycle, and (3) tests covering both. Under that rule, **none of the eight tools is ready**.

* **Partial:** `nmem_remember`, `nmem_recall`, and `nmem_show` have useful local primitives, but not the upstream contract and/or not agent-tool routing and lifecycle tests.
* **Missing:** `nmem_remember_batch`, `nmem_context`, `nmem_todo`, `nmem_auto`, and `nmem_suggest` have no corresponding native implementation and route. `nmem_context` must not be credited from the agent's query-specific recall injection.
* A repository-wide read-only search for all eight exact `nmem_*` identifiers under `WaifuClaw` and `WaifuClawTests` produced **zero Swift matches**. NativeAgentEngine offers only `list_files`, `read_file`, and optionally `propose_edit` (not these memory tools).

## Transport and implementation boundary

The upstream package is **MIT** (`/home/ubuntu/neural-memory-source-audit/LICENSE:1-20`) and exposes its Python implementation through MCP. Its docs describe **63 tools via MCP stdio** (`docs/api/mcp-tools.md:1-7`); `server.py:826-945` reads JSON-RPC from `sys.stdin` and states that `nmem-mcp` uses stdio by default. `MCPServer.call_tool` has concrete dispatch entries for all eight requested names (`server.py:357-461`). That is a Python/MCP service architecture, not an iPhone-native implementation.

WaifuClaw's implementation is a separate on-device SQLite graph: actor-isolated, per-project, with no remote call, model invocation, credential storage, or cross-project query (`LocalNeuralMemoryStore.swift:20-25`, `61-98`, `445-525`). It has deliberately narrow user-approved writes: `capture` is the only production write method and rejects anything other than `.userApproved` (`LocalNeuralMemoryStore.swift:106-124`; `LocalNeuralMemoryModels.swift:52-78`). This is a materially different privacy/security policy from upstream model-callable `nmem_remember` and `nmem_auto`.

WaifuClaw also contains a **separate remote MCP connector** under `WaifuClaw/Local/MCP`. It makes remote `connection.client.callTool` calls (`NativeMCPConnector.swift:141-190`) after `NativeMCPUserConsent`; tests use `https://mcp.example.com/mcp` and explicitly approve a remote tool call (`NativeMCPTests.swift:71-84`, `198-257`). `NativeAgentEngine.swift` has no MCP/connector reference and its tool catalog is only the file/proposal catalog (`NativeAgentEngine.swift:176-178`, `326-342`). Therefore, a manually configured remote MCP server—even if it serves NeuralMemory—is **not counted** as phone-native Core Memory parity.

## Current iOS reachability and test findings

1. **Local user path exists, but is intentionally narrow.** `NativeMemoryView` lets a user choose a security-scoped folder, creates a project identity, manually recall, manually save an approved fact, delete/purge, and prepare a local JSON export (`NativeMemoryView.swift:34-171`, `223-267`, `311-415`). This is substantial phone-native functionality, but not an MCP tool API.
2. **The only actual agent-cycle memory behavior is pre-provider recall injection.** `NativeAgentController` reads `NativeMemoryConsent().isEnabled(for: runProjectID)` and passes it to the engine (`NativeAgentController.swift:124-171`). The engine recalls at most three matching facts only if memory is enabled, file tools are offered, and a workspace exists, then appends them to the system prompt and records `memory.recalled` (`NativeAgentEngine.swift:135-173`). It never invokes `capture`, never exposes any `nmem_*` function, and its `tools` list stays file/proposal-only (`176-178`, `326-342`).
3. **Existing tests are useful but insufficient for readiness.** Store tests prove persistence, project isolation, deterministic direct-vs-spread ranking, delete/purge, and provenance/export (`NativeNeuralMemoryTests.swift:16-179`). Consent tests prove opt-in/per-project isolation and reject invalid project IDs (`NativeMemoryConsentTests.swift:6-34`). Agent tests prove generic completion/file denial/proposed-edit lifecycle only (`NativeAgentEngineTests.swift:6-109`). There is no memory-enabled native agent lifecycle test, no exact nmem schema/handler test, and no eight-tool dispatch test.
4. **Current failure/success exits are observable for future tests.** On no further tool calls the engine records `run.completed`, sets phase `.finished`, yields `.completed`, and finishes (`NativeAgentEngine.swift:183-218`); failures record `run.failed`, cancellation records `run.cancelled` (`277-295`). Every proposed agent-lifecycle test above should assert one of these terminal paths and inspect durable `LocalRunStore` events—not merely inspect a returned string.

## Blocking parity gaps and implementation order

1. **Introduce a native Core Memory tool boundary:** typed Codable schemas and an agent-visible, consent-aware dispatcher. It must be separate from the existing remote MCP connector and from passive prompt injection.
2. **Choose a parity policy before implementing writes:** upstream allows agent-triggered remember/auto writes; WaifuClaw currently requires a per-fact human approval. Preserve the latter unless product policy deliberately changes. A “pending approval” result is safer than silently claiming an upstream write succeeded.
3. **Expand the local data model:** types, priorities, tags, expiry, tier/hot/cold, lifecycle, valid-time fields, trust, provenance/synapse variants, stable compatible IDs, access telemetry, and searchable indexes are required across the eight APIs. The current two-edge fact graph is not enough.
4. **Build recall/context behavior deliberately:** local deterministic token/co-occurrence recall is a credible foundation, but not equivalent to upstream `ReflexPipeline`, layers, filters, exact mode, graphs, ghosts, or optimized context. Do not silently drop input fields.
5. **Add the table's contract and lifecycle tests before status can change to Ready.** Tests must cover normal success, invalid input, project isolation, permission denial/revocation, user cancellation, durable tool events, and the terminal `finished` exit.

## Risks

* **False parity risk:** Calling the current prompt injection “`nmem_recall`” or using local list/export as “`nmem_show`” hides missing schemas, routing, and results.
* **Privacy/consent regression:** Mirroring upstream `nmem_auto` or model-callable `nmem_remember` without user review would contradict explicit local source policy and UI promises.
* **Data boundary risk:** Existing project isolation is strong; a new adapter must retain project scoping on every ID lookup and every agent response.
* **Semantic drift risk:** The upstream batch handler/schema discrepancy (`trust_score` and `source_id`) must be documented in native tests rather than accidentally normalized away.
* **Remote substitution risk:** The manually approved network MCP connector is independently valuable, but it is neither reachable from `NativeAgentEngine` nor a substitute for an offline/on-device Core Memory implementation.
