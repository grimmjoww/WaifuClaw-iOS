## Cross-cutting implementation gates before any row can become Ready

1. **Phone-native routing:** introduce a local tool contract/registry and dispatcher used by `NativeAgentEngine`, with the 19 exact names, input validation, normal results/errors, and event recording. Do not route through `NativeMCPConnector` and do not launch/embed the upstream Python stdio process as a claim of native Swift parity.
2. **Lifecycle reachability:** each tool needs a model-offer policy, a dispatch branch, and terminal-event behavior that is testable with a scripted provider. The current engine rejects all names other than `list_files`, `read_file`, and `propose_edit` (`I/WaifuClaw/Local/Agent/NativeAgentEngine.swift:298-343`).
3. **Consent and isolation:** preserve project-scoped SQLite isolation and required `.userApproved` permanent fact capture (`I/WaifuClaw/Local/Memory/LocalNeuralMemoryStore.swift:106-124`). Model context sharing remains a separate, per-project opt-in (`I/WaifuClaw/Local/Memory/NativeMemoryConsent.swift:3-29`; `I/WaifuClaw/Local/Memory/NativeMemoryView.swift:285-304`). File watching, imported packages, offload retention, safety boundaries, and goal/refinement mutations require their own explicit UX decisions.
4. **Test bar:** for every row, add a direct XCTest for the exact public contract and a `NativeAgentEngine` stream test that asserts allowed/denied call behavior, persistent state where applicable, `tool.completed` or `tool.failed`, and a terminal `run.completed`, `run.failed`, or `run.cancelled` event. Existing generic local-memory tests must not be renamed or counted as named-tool parity.
5. **No false equivalence:** the upstream's MIT license and source attribution are documented at `I/WaifuClaw/Local/Memory/UPSTREAM.md:3-16`, which also explicitly says this is a new small Swift implementation rather than a full port. Maintain that disclosure unless the missing semantics, routing, and tests actually land.
