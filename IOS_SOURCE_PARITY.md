**No production mocks rule:** Xcode previews and XCTest may use fixtures only outside the production target. Every mounted runtime path must use a real local store or provider, or display an honest empty/error/unavailable state. A feature is not considered shipped without discoverable navigation, needed consent/settings, persisted behavior, unit/UI tests, and a release build. The desktop-remote and mock-only leaves remain in the repository as references but are excluded from the app target; they must not be reintroduced as live features.

**Platform boundaries:** iOS 17 cannot guarantee always-on background jobs or arbitrary downloaded executable plugins. User-selected Files folders require security-scoped access. Phone-only describes the **agent runtime and project state**; a user-chosen HTTPS coding model or Jev service can still receive request data when enabled. Local Core ML/Foundation Models support is a distinct future mode, not implicitly provided by BYOK.
