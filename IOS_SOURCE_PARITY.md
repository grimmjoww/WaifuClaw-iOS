# WaifuClaw Source → iPhone parity ledger

**Specification:** [`WaifuClaw-Source/README.md`](https://github.com/grimmjoww/WaifuClaw-Source/blob/main/README.md), its [capability registry](https://github.com/grimmjoww/WaifuClaw-Source/blob/main/frontend/src/core/capabilities/registry.ts), selected [NeuralMemory MIT source](https://github.com/grimmjoww/neural-memory), and the owner's illustrated desktop reference. The reference is a **visual aspiration**, not evidence that an illustrated feature ever ran. All statuses refer to this iOS feature branch; source code is not equivalent to an installed or signed app.

**No production mocks:** All mounted runtime views must use a real on-device store/network provider or an honest empty, permission, error or unavailable state. Fixture responses belong in XCTest only. The legacy desktop-remote/mock-only leaves are retained as reference source but excluded from the compiled app target.

**iPhone boundaries:** iOS 17 cannot guarantee indefinitely running background work or arbitrary downloaded executable plugins. Files requires an individual user grant. “Standalone” describes the **agent runtime and storage**; external BYOK providers and optional Jev still receive whatever request data the user intentionally sends. Continued processing, hosted workers and an entirely offline model are separate future milestones, not implied by this branch.
