**No production mocks rule:** Xcode previews/XCTest may use synthetic fixtures **only in non-production paths**. Runtime navigation must use an actual local provider or an honest empty/error/unavailable state, never `Mock*` data. A feature is not shipped if it lacks a discoverable entry point, needed user control/setting, persisted state, and an evidence-backed end-to-end flow. Do not hide incomplete rows behind a decorative active indicator.

**Platform constraints:** Apple app sandbox limits cross-app filesystem access and native execution; obtain user consent for project folders and tools. iOS 17 cannot guarantee an always-on worker; offer resume/checkpoints. Third-party plugins are data-only manifests/app-defined capabilities or explicitly chosen remote services until App Store rules permit a stronger mechanism. The core remains usable without a Windows desktop or WaifuClaw-operated server.
